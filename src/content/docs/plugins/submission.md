## How to submit your plugin
- See [Creating plugins](/plugins/index.mdx##Plugin-Setup) to make sure your plugin complies with everything mentioned
- Once you finish developing the plugin, fork the [Vencord repository](https://github.com/Vendicated/Vencord)
- Put your plugin in the plugins directory (Vencord/src/plugins) in it's own folder with the name of the plugin in [camelCase](https://en.wikipedia.org/wiki/Camel_case). For example `myFirstPlugin` (NOT `MyFirstPlugin` or `my first plugin`)
- Create a pull request on the Vencord repository

## Things to keep in mind
- Make sure you know git
- Don't make AI write slop, at least edit it yourself
- Make sure the plugin is actually useful and people will use it
